# Руководство по тестированию системы ачивок CyberAware

## Быстрый старт

### 1. Запуск сервера
```bash
cd CyberAware/myworld/cyberaware
python manage.py runserver
```

### 2. Создание тестового пользователя
```bash
# Базовый тест (получит ~6 ачивок)
python manage.py test_achievements --email test@example.com

# Полная симуляция (получит ~21 ачивка)
python manage.py simulate_user_journey --email superuser@example.com --reset
```

### 3. Просмотр результатов
1. Откройте http://127.0.0.1:8000
2. Войдите с созданными учетными данными
3. Перейдите в профиль для просмотра ачивок

## Тестовые сценарии

### Сценарий 1: Новый пользователь
**Цель**: Проверить получение базовых ачивок

```bash
python manage.py test_achievements --email newbie@test.com
```

**Ожидаемый результат**:
- Пользователь получит 6 ачивок
- XP: 25
- Level: 0

**Цель**: Проверить все типы ачивок включая стрики и завершение курсов

```bash

```

**Ожидаемый результат**:
- Пользователь получит 21+ ачивок (72%+ от всех)
- XP: 400+
- Level: 2+
- Включены ачивки всех категорий

### Сценарий 3: Сброс прогресса
**Цель**: Проверить корректность повторного тестирования

```bash
python manage.py simulate_user_journey --email existing@test.com --reset
```

**Ожидаемый результат**:
- Весь предыдущий прогресс удален
- Заново получены все возможные ачивки

## Проверка функциональности

### Проверка логики ачивок

#### Ачивки обучения
- [ ] **Первый шаг** - появляется после завершения любой лекции
- [ ] **Любознательный** - появляется после 5 лекций
- [ ] **Погружение** - появляется после 10 лекций
- [ ] **Начало пути** - появляется после завершения первого курса на 50%+
- [ ] **Без пропусков** - появляется при 100% завершении курса

#### Ачивки тестирования
- [ ] **Проверка знаний** - первый пройденный тест
- [ ] **Отличник** - 100% правильных ответов
- [ ] **Почти идеально** - 80%+ правильных ответов
- [ ] **Сдал с первого раза** - успех с первой попытки на 100%
- [ ] **Не сдаюсь** - успех после предыдущих неудач

#### Ачивки активности
- [ ] **Возвращаюсь** - вход 2 дня подряд
- [ ] **Привычка** - вход 5 дней подряд
- [ ] **Неделя с нами** - вход 7 дней подряд
- [ ] **Постоянство** - вход 14 дней подряд

### Проверка интерфейса

#### Профиль пользователя
- [ ] Отображается количество ачивок
- [ ] Показываются полученные ачивки с названиями
- [ ] Показываются описания ачивок
- [ ] Корректно отображаются иконки
- [ ] Ачивки сгруппированы логично

#### Административная панель
- [ ] Видны записи MemberAchievement
- [ ] Можно фильтровать по коду ачивки
- [ ] Можно найти ачивки пользователя
- [ ] Отображается время получения

## Устранение проблем

### Проблема: Ачивки не появляются
**Проверьте**:
1. Выполнены ли миграции: `python manage.py migrate`
2. Корректно ли сохраняется прогресс пользователя
3. Вызывается ли `_evaluate_member_achievements` после действий

### Проблема: Неверное количество ачивок
**Проверьте**:
1. Логику в `_evaluate_member_achievements`
2. Условия получения конкретной ачивки
3. Данные в базе (MemberLectureProgress, MemberQuizAttempt)

### Проблема: Дублирование ачивок
**Решение**: Ограничение `unique_together` в модели должно предотвращать дубли

### Проблема: Ачивки не отображаются в профиле
**Проверьте**:
1. Передается ли `achievements` в контекст шаблона
2. Корректность шаблона profile.html
3. Наличие CSS стилей для ачивок

## Автоматизированное тестирование

### Создание batch тестов
```bash
# Создать 5 тестовых пользователей с разным прогрессом
for i in {1..5}; do
  python manage.py test_achievements --email "user$i@test.com"
done

# Создать одного "супер-пользователя"
python manage.py simulate_user_journey --email "admin@test.com"
```

### Проверка производительности
Для проверки производительности с большим количеством пользователей:

```python
# В Django shell
from members.models import Member
from members.views import _evaluate_member_achievements
import time

# Замерить время оценки ачивок для всех пользователей
start_time = time.time()
for member in Member.objects.all():
    _evaluate_member_achievements(member)
end_time = time.time()

print(f"Evaluated achievements for {Member.objects.count()} users in {end_time - start_time:.2f}s")
```
