# CyberAware - Система ачивок

## Обзор

Система ачивок в CyberAware предназначена для мотивации пользователей к изучению кибербезопасности через игровые элементы. Пользователи получают ачивки за различные действия: прохождение лекций, успешные тесты, активность на платформе и достижение определенных уровней.

## Архитектура системы

### Модели данных

#### MemberAchievement
Хранит связь между пользователем и полученными ачивками:
- `member` - связь с пользователем
- `code` - уникальный код ачивки
- `earned_at` - дата и время получения ачивки

#### Связанные модели
- `MemberLectureProgress` - прогресс по лекциям
- `MemberQuizAttempt` - попытки прохождения тестов
- `MemberDailyActivity` - ежедневная активность для стриков

### Категории ачивок

Система содержит **29 ачивок** в **6 категориях**:

#### 1. Обучение / Контент (6 ачивок)
- **Первый шаг** - прочитал первую лекцию
- **Начало пути** - прошёл первый модуль целиком
- **Любознательный** - прочитал 5 лекций
- **Погружение** - прочитал 10 лекций
- **До конца** - дочитал лекцию до 100%
- **Без пропусков** - прошёл модуль без скипов

#### 2. Тесты и задания (6 ачивок)
- **Проверка знаний** - прошёл первый тест
- **Сдал с первого раза** - тест пройден без ошибок
- **Почти идеально** - результат 80%+
- **Отличник** - 100% за тест
- **Не сдаюсь** - перепрошёл тест после ошибки
- **Закрепил материал** - прошёл все тесты модуля

#### 3. Кибербезопасность (тематические) (5 ачивок)
- **Пароль под замком** - изучил тему паролей
- **Фишинг? Не сегодня** - прошёл лекцию про фишинг
- **Доверяй, но проверяй** - тема соц. инженерии
- **Цифровая гигиена** - изучил базовые правила безопасности
- **Безопасный старт** - завершил вводный курс

#### 4. Активность (4 ачивки)
- **Возвращаюсь** - зашёл 2 дня подряд
- **Привычка** - 5 дней подряд
- **Неделя с нами** - 7 дней подряд
- **Постоянство** - 14 дней подряд

#### 5. Прогресс (5 ачивок)
- **Первый уровень** - достиг уровня 2
- **Расту** - достиг уровня 5
- **Опыт имеет значение** - 100 XP
- **На опыте** - 500 XP
- **Ветеран обучения** - 1000 XP

#### 6. Завершение (3 ачивки)
- **Финиш** - завершил курс
- **Осознанный пользователь** - прошёл все модули
- **CyberAware** - открыл все базовые темы

## Логика работы

### Проверка ачивок
Функция `_evaluate_member_achievements(member)` анализирует активность пользователя и определяет, какие ачивки он заслужил. Проверка происходит автоматически:

1. **При логине** - отслеживается ежедневная активность
2. **После прохождения теста** - проверяются все связанные ачивки
3. **При просмотре профиля** - обновляется список ачивок

### Отображение в профиле
В профиле пользователя показываются:
- Количество полученных ачивок
- Список ачивок с названиями и описаниями
- Иконки для каждой ачивки

## Файлы системы

### Backend (Django)
- `models.py` - модель MemberAchievement
- `views.py` - логика проверки и выдачи ачивок
- `templates/profile.html` - отображение ачивок в профиле

### Management команды
- `test_achievements.py` - тестирование базовой функциональности
- `simulate_user_journey.py` - полная симуляция пользовательского пути
- `show_achievements.py` - просмотр всех доступных ачивок

## Использование команд

### Просмотр всех ачивок
```bash
python manage.py show_achievements
```

### Тестирование системы
```bash
python manage.py test_achievements --email test@example.com
```

### Симуляция полного пути пользователя
```bash
python manage.py simulate_user_journey --email journey@example.com --reset
```

## Интеграция

### Автоматическое начисление ачивок
Ачивки начисляются автоматически при:
- Завершении лекций
- Прохождении тестов  
- Ежедневном входе в систему
- Достижении определенных уровней XP

### Расширение системы
Для добавления новых ачивок:

1. Добавить код ачивки в `ACHIEVEMENT_CATEGORIES` в `views.py`
2. Добавить логику проверки в функцию `_evaluate_member_achievements`
3. При необходимости создать миграцию для обновления данных

## Особенности реализации

### Производительность
- Ачивки проверяются только при необходимости
- Используется кэширование уже полученных ачивок
- Дублирование ачивок предотвращается через `unique_together`

### Тематические ачивки
Система автоматически определяет тематику лекций по ключевым словам в названиях:
- "парол" / "password" → ачивка "Пароль под замком"
- "фишинг" / "phishing" → ачивка "Фишинг? Не сегодня"
- "соц. инженер" / "social engineering" → ачивка "Доверяй, но проверяй"

### Стрики активности
Система отслеживает последовательные дни входа пользователя для ачивок активности.

## Миграции

```bash
python manage.py makemigrations

```

## Тестирование

Система включает comprehensive тесты через management команды, которые позволяют:
- Создать тестового пользователя
- Симулировать различные сценарии использования
- Проверить корректность начисления ачивок
- Протестировать все категории ачивок

Результат тестирования показывает процент завершения и детальную статистику по каждой категории ачивок.
